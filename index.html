Как установить мод

1

Скачайте архив

Загрузите .zip-файл нужной лиги. Распаковывать архив вручную не нужно.

2

Добавьте в меню игры

На экране новой карьеры нажмите «Установить мод…» или просто перетащите архив в окно игры.

3

Выберите клуб

Как добавить мод на сайт

Откройте файл manifest.json в корне репозитория и добавьте запись в массив mods.

1. Архив в папке mods/ репозитория

{
  "source": "repo",
  "file": "mods/khl-2026-27.zip"
}

Название, описание, версия, эмблемы и список клубов прочитаются автоматически из mod.json и roster.json внутри архива.

2. Ссылка на Google Диск

{
  "source": "drive",
  "name": "НХЛ 2026/27",
  "description": "Описание мода…",
  "author": "ВашНик",
  "version": "1.0",
  "url": "https://drive.google.com/file/d/ID_ФАЙЛА/view?usp=sharing"
}

Для внешних ссылок укажите метаданные вручную — обычная ссылка «Поделиться» сама преобразуется в прямую ссылку для скачивания.

Поля mod.json внутри архива

{
  "name": "КХЛ 2026/27",
  "description": "Описание сезона и состава лиги",
  "author": "ClubGames",
  "version": "1.0",
  "roster": "roster.json",
  "schedule": "schedule.json"
}
