Как добавить мод

Отредактируйте файл manifest.json в репозитории. Добавьте запись в массив mods:

1. Архив из папки mods/ репозитория

{
  "source": "repo",
  "file": "mods/khl-2026-27.zip"
}

Данные (название, описание, автор, версия) берутся автоматически из mod.json внутри архива.

2. Ссылка на Google Диск

{
  "source": "drive",
  "name": "НХЛ 2026/27",
  "description": "Описание мода…",
  "author": "ВашНик",
  "version": "1.0",
  "url": "https://drive.google.com/file/d/ID_ФАЙЛА/view?usp=sharing"
}

Для Google Диска укажите название и описание сами — сайт не может прочитать архив на Диске.

Ссылки на скачивание игры

Добавьте/измените массив game.links в manifest.json — они появятся в блоке «Скачать игру».
