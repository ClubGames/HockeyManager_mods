Как подключить мод

  1. 01
    Скачайте ZIP-архив лиги

    Распаковывать архив вручную не требуется — игра читает его сама.

  2. 02
    Нажмите «Установить мод…»

    Кнопка находится на стартовом экране новой карьеры. Архив можно просто перетащить в окно игры.

  3. 03
    Выберите лигу и клуб

    Эмблемы, составы, контракты и расписание регулярки подключатся автоматически.

Одинаково работает на Windows, Android и в браузерной версии.

Как добавить мод на сайт

Список раздаваемых архивов задаётся в файле manifest.json в корне репозитория (массив mods). Поддерживаются два способа хранения:

1. ZIP-архив в папке mods/ репозитория

{
  "source": "repo",
  "file": "mods/khl-2026-27.zip"
}

Название, описание, версия, эмблемы клубов и сводка по ростеру считываются автоматически из mod.json, roster.json и schedule.json внутри архива.

2. Внешняя ссылка на Google Диск

{
  "source": "drive",
  "name": "НХЛ 2026/27",
  "description": "Регулярный чемпионат, 32 клуба с актуальными составами.",
  "author": "ВашНик",
  "version": "1.0",
  "url": "https://drive.google.com/file/d/ID_ФАЙЛА/view?usp=sharing"
}

Для внешних ссылок укажите метаданные вручную — браузер не скачивает архив с Диска заранее. Обычная ссылка «Поделиться» сама преобразуется в прямую загрузку.

Формат mod.json внутри архива

{
  "name": "КХЛ 2026/27",
  "description": "Описание сезона, количества клубов и особенностей ростера.",
  "author": "ClubGames",
  "version": "1.0",
  "roster": "roster.json",
  "schedule": "schedule.json"
}

Ссылки в блоке «Скачать игру» настраиваются в том же manifest.json через массив game.links.
