# HockeyManager — Моды

Статический сайт каталога модов и сборок для **Hockey Simulator Manager**.
Работает на GitHub Pages напрямую из ветки, без сборки, сервера и базы данных.

## Что внутри

```
index.html          ← главная страница каталога
assets/styles.css   ← светлое оформление страницы
assets/app.js       ← чтение manifest.json и распаковка архивов в браузере
assets/fonts/       ← локальный шрифт Golos Text (woff2, 400–700)
assets/img/         ← иконка приложения и favicon
assets/vendor/      ← локальная копия JSZip
manifest.json       ← список модов и ссылок на сборки игры
mods/               ← ZIP-архивы модов из репозитория
.nojekyll           ← отключает обработку Jekyll на GitHub Pages
```

## Как добавить мод

Отредактируйте `manifest.json` (массив `mods`). Два варианта:

### 1. Архив лежит в папке `mods/` репозитория
```json
{
  "source": "repo",
  "file": "mods/khl-2026-27.zip"
}
```
Название, описание, автор и версия берутся **автоматически** из `mod.json`
внутри архива. Сайт сам распаковывает ZIP в браузере (через JSZip) и читает
`mod.json`. Данные внутри `mod.json` должны быть такими:

```json
{
  "name": "КХЛ 2026/27",
  "description": "Континентальная хоккейная лига, сезон 2026/27…",
  "author": "ClubGames",
  "version": "1.0",
  "roster": "roster.json",
  "schedule": "schedule.json"
}
```

### 2. Ссылка на Google Диск
```json
{
  "source": "drive",
  "name": "НХЛ 2026/27",
  "description": "Описание мода…",
  "author": "ВашНик",
  "version": "1.0",
  "url": "https://drive.google.com/file/d/ID_ФАЙЛА/view?usp=sharing"
}
```
Для Google Диска укажите название и описание сами — сайт не может прочитать
архив на Диске. Ссылка автоматически преобразуется в прямую ссылку для скачивания.
Достаточно вставить обычную «share»-ссылку вида
`https://drive.google.com/file/d/.../view?usp=sharing`.

После правки сделайте `git commit` и `git push` — сайт обновится сам.

## Как опубликовать (GitHub Pages)

1. Зайдите в **Settings → Pages** репозитория.
2. В **Build and deployment → Source** выберите **Deploy from a branch**.
3. Выберите ветку, где лежат файлы сайта (например `main`) и папку **/ (root)**.
4. Сохраните. Через 1–2 минуты сайт будет по адресу
   `https://<ваш-логин>.github.io/HockeyManager_mods/`.

## Как сделать сайт публичным, а исходный код — приватным

Это самый частый вопрос. Нужно сделать **сам репозиторий приватным**:

- **Settings → General → Danger Zone → Change visibility → Private.**

GitHub Pages публикует **только отрендеренный сайт** (файлы из выбранной ветки/папки).
Посетители по адресу страницы видят сайт, но **не могут** открыть `github.com/.../repo`
и смотреть исходники, историю коммитов, `manifest.json` и т.д.

Важно понимать: файлы, которые попадают в опубликованную ветку (в том числе ZIP-архивы
в папке `mods/`), становятся доступны по прямой ссылке на сайте — это и нужно для скачивания.
«Приватность» скрывает именно **репозиторий** (его структуру, историю, настройки),
а не сами раздаваемые файлы.

Если хотите спрятать ещё и сами архивы (чтобы их нельзя было скачать напрямую по URL,
а только через кнопку на сайте) — храните тяжёлые моды на Google Диске (вариант 2) и
не кладите их в репозиторий. Ссылки на Диск в `manifest.json` приватны для посторонних.
